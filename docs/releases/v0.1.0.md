# URDF Visualizer Release Notes - v0.1.0

Status: release baseline  
Baseline: `package.json` version `0.1.0` and the cleaned `main` history  
Tag: `v0.1.0`

## Overview

`v0.1.0` is the initial release baseline for URDF Visualizer, a browser-based tool for loading, rendering, inspecting, and measuring URDF and Xacro robot models without requiring a local ROS runtime.

## Major Features

### Browser-Based Robot Visualization

- Render URDF and Xacro robot models with Three.js in a React/Vite application.
- Load bundled sample models from the generated public manifest.
- Display robot geometry with grid, world axes, link frames, joint frames, wireframe mode, and optional shadows.

### URDF, Xacro, And Mesh Loading

- Load a single `.urdf` or `.xacro` file from the browser.
- Load a full project folder or drag-and-drop a directory containing robot descriptions and mesh assets.
- Resolve common ROS-style paths, including `package://` resources and relative URDF mesh paths.
- Parse Xacro files in the browser, including recursive include flattening.
- Render STL, DAE, and OBJ mesh assets through Three.js loaders.

### Inspection And Control

- Select links in the 3D viewer and inspect global/local transform information.
- Inspect position, RPY orientation, quaternion values, parent/child joint information, joint type, axis, and limits.
- Control movable joints through sliders and reset joint values.
- Select and highlight corresponding robot parts between the 3D scene and the structure tree.

### Kinematic Structure Tree

- View a fullscreen link/joint hierarchy for loaded robot models.
- Fold and expand tree branches, inspect joint metadata, and synchronize tree selection with 3D highlighting.
- Toggle the tree from the UI or keyboard shortcut.

### Measurement Tool

- Enable measurement mode from the UI or keyboard shortcut.
- Place multiple measurement points on model surfaces and display segment distances.
- Snap measurement points to joint centers when joint helpers are visible.
- Remove measurement points directly from the scene.

## Fixes And Stabilization

- Improved Xacro parsing and large Xacro project rendering.
- Fixed selected joint/link highlighting, tree graph interaction, and tree graph styling issues.
- Corrected coordinate-axis display and Z/Y axis alignment behavior.
- Blocked accidental `Ctrl + R` refresh while inspecting loaded models.
- Removed the earlier backend dependency so the app can run as a static web application.

## Deployment Notes

- Development server: `npm run dev`
- Production build: `npm run build`
- Preview built output: `npm run preview`
- GitHub Pages deployment script: `npm run deploy`

Publish this release by pushing the annotated `v0.1.0` Git tag after the cleaned history has been reviewed and pushed.

## Compatibility Notes

- The current implementation is a browser application and relies on Web APIs for file and folder selection.
- No breaking upgrade path is listed because this is the first documented release baseline.
