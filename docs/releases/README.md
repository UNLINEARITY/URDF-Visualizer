# Release Notes

This directory stores user-readable release notes for URDF Visualizer.

## Index

- `v0.1.0.md` - initial release notes based on the `0.1.0` package metadata and cleaned release history.

## Maintenance Rules

- Keep one Markdown file per released version, named `vX.Y.Z.md`.
- Use `CHANGELOG.md` as the concise version history and these release notes as the user-facing explanation.
- Base each release note on Git history, tagged diffs, package metadata, and the actual repository content.
- Mark a file as a draft when the corresponding Git tag does not exist yet.
- Call out breaking changes, removals, deployment changes, and required upgrade actions in a visible section.
- Do not rewrite or replace older release notes unless the user explicitly asks for a correction.
